# Social Golfers

Projekt per detyren Social Golfers Problem. Eshte bere me DFS dhe backtracking ne Java.

## Run

```
javac -d out src/*.java
java -cp out Golf 8 4 5
```

Argumentet jane: grupet, lojtaret ne grup, javet.

## Modeli

Variablat jane lojtaret ne grupe per cdo jave. Domain eshte 0 deri n-1.
Objective function eshte score() qe numeron sa here takohen perseri lojtaret.

Programi gjen zgjidhje per 32 lojtare per 5 jave.
